## What is OpusForge?

Most AI-generated websites suffer from the exact same failure modes: purple gradient blobs, unreadable glassmorphism, generic centered three-column cards, floating emoji badges ("New ✨"), sluggish CSS transitions, broken layout shifts (CLS), and empty copywriting loaded with corporate buzzwords ("supercharge your workflow").

**OpusForge** is an integrated AI design engineering suite and autonomous build pipeline that replaces cookie-cutter AI output with bespoke, senior-level digital craft. It unifies:

1. **Figma Conduit (MCP):** Live token harvesting, container dimension inspection, and prototype spring curve extraction without manual copy-pasting.
2. **Structural Rigor:** UX topology, surface mode selection (Workspace, Editorial, Reading), and defensive edge-case hardening.
3. **Editorial Cadence:** High-conviction typography, the strict "one section per screen" rule (1440x900), and punchy, human copywriting.
4. **Kinetic Physics:** Interruptible 60fps/120fps spring dynamics, tactile click depth, rubber-banding gesture manipulation, and strict compositor layer budgets.
5. **Aesthetic Sanitization:** Comprehensive de-templating rules that eradicate amateur AI signatures and restore authentic human design direction.

## Quick Start

### 1. Installation
Clone OpusForge directly into your agent workspace (Antigravity, Cursor, Claude Code, or Codex):
```bash
git clone https://github.com/Gana-Y/opus-forge.git
cd opus-forge
```

### 2. Connect Figma MCP (Optional but Recommended)
Enable the official Figma MCP bridge in your editor configuration:
```json
{
  "mcpServers": {
    "figma": {
      "command": "npx",
      "args": ["-y", "@figma/mcp-server"]
    }
  }
}
```
*(For detailed setup and desktop app bridging, see [SETUP.md](disciplines/figma-conduit/SETUP.md).)*

### 3. Run the Autonomous Flagship Pipeline
Trigger the complete 6-stage build pipeline with a single prompt:
```text
opus-pipeline full-build for https://www.figma.com/design/:fileKey/:fileName?node-id=1:675
```
Or for a greenfield build without Figma:
```text
opus-pipeline full-build: Build a flagship, high-converting landing page for an autonomous code execution engine.
```

## The 6-Stage Sovereign Pipeline

When invoked via `opus-pipeline`, OpusForge executes through six strict, non-skippable stages separated by verification gates:

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│   STAGE 1    │     │   STAGE 2    │     │   STAGE 3    │
│ Token Intake ├────►│ UX Blueprint ├────►│  Editorial   │
│ (Figma MCP)  │     │ (Mode & IA)  │     │    Craft     │
└──────┬───────┘     └──────┬───────┘     └──────┬───────┘
       │                    │                    │
    [Gate 1]             [Gate 2]             [Gate 3]
       │                    │                    │
┌──────▼───────┐     ┌──────▼───────┐     ┌──────▼───────┐
│   STAGE 4    │     │   STAGE 5    │     │   STAGE 6    │
│   Kinetic    ├────►│  Defensive   ├────►│  Aesthetic   │
│    Motion    │     │ Fortification│     │ Sanitization │
└──────────────┘     └──────────────┘     └──────────────┘
```

1. **Stage 1 (`token-intake`):** Harvests Figma variables, layout bounds, and spring prototype curves into semantic CSS tokens.
2. **Stage 2 (`blueprint`):** Determines surface mode (Workspace, Editorial, Reading) and maps spatial container topology.
3. **Stage 3 (`editorial-craft`):** Enforces 1-section-per-screen rhythm (1440x900) and crafts declarative, zero-jargon copywriting.
4. **Stage 4 (`kinetic-polish`):** Engineers tactile button depth, modal backdrops, and composite-only spring animations.
5. **Stage 5 (`fortify`):** Stress-tests layouts against 250+ character strings, broken data, zero-state views, and WCAG AA focus rings.
6. **Stage 6 (`de-generic`):** Strips residual purple gradient halos, glossy emoji chips, and restores bespoke visual authority.

## Standalone Component Mode

You do not need to run the full pipeline every time. Any discipline can be invoked independently to solve a targeted challenge.

👉 **Browse the full catalogue in [DISCIPLINES-CATALOG.md](DISCIPLINES-CATALOG.md)** (or `SKILLS-CATALOG.md`).

### Highlights:
- **Need instant physics-based animation?** Run `motion-choreography` or `tactile-craft-engineering`.
- **Need to stress-test broken or extreme data?** Run `chaos-ui-tester`.
- **Need non-blocking stacked toasts?** Run `toast-mechanics`.
- **Need to sanitize an AI-generated template?** Run `de-generic`.
- **Need to eliminate slow layout repaints?** Run `frame-budget-guard`.
